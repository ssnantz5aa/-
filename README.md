# Slate — 붙여넣는 일정 관리

실장에게 받은 일정 메시지를 붙여넣으면 행사명, 날짜, 시간, 장소, 연락처, 에이전시, 페이, 세금공제, 지급일을 **규칙 기반으로** 뽑아 아이폰 캘린더에 넣는 모바일 웹앱입니다. 의전·행사 일을 하는 프리랜서를 위해 만들었습니다. AI나 외부 서버를 쓰지 않으며 모든 데이터는 기기(localStorage)에만 저장됩니다.

## 실행

빌드 과정이 없는 정적 웹앱입니다(ES 모듈 사용).

```bash
npm start          # http://localhost:5173
npm test           # 분석기 테스트 (node --test)
```

GitHub Pages(`main` 브랜치 루트)로 배포합니다. 아이폰 Safari에서 공유 → ‘홈 화면에 추가’를 하면 앱처럼 실행됩니다.

## 화면

하단 탭은 **홈 · 캘린더 · 일정 추가 · 페이 · 설정**입니다. 검색은 홈과 캘린더 위쪽의 돋보기로 엽니다.

| 화면 | 내용 |
| --- | --- |
| 홈 | 날짜·인사말, 바로 붙여넣기 입력창, 오늘 일정, 다가오는 일정 |
| 일정 추가 | 넓은 입력칸, 붙여넣기·예시, 직접 입력 |
| 분석 결과 | 항목 편집, 불확실한 값 경고, 직접 쓰는 메모, 주 버튼 ‘아이폰 캘린더에 추가’ |
| 일정 상세 | 지도·전화·문자·복사, 아이폰 캘린더에 추가, Google 캘린더 링크, 복제·삭제(실행 취소 가능) |
| 캘린더 | 월·주·일 보기, 스와이프 이동 |
| 페이 | 받을 페이(지연 건 먼저), 예정 페이, 입금 완료(최근 30일 / 이전 내역), 입금 체크 |
| 검색 | 제목·장소·실장·에이전시·메모·원문 검색, 기간 필터 |
| 설정 | 주 시작 요일, 12/24시간 표시, 기본 캘린더 보기, 백업 저장/불러오기, 전체 .ics 내보내기, 전체 삭제 |

## 아이폰 캘린더로 보내기

기기 안에서 `.ics` 파일을 만들어 내려받게 하면 아이폰 Safari가 일정 추가 화면을 띄웁니다. 일정의 메모 칸에는 **원문이 그대로** 들어가고, 직접 쓴 메모가 있으면 원문 위에 넣습니다. 저장될 캘린더는 아이폰의 추가 화면이나 ‘설정 → 캘린더 → 기본 캘린더’에서 정합니다(웹앱은 캘린더 목록을 읽을 수 없음).

## 디자인

`css/app.css` 맨 위 `:root` 토큰으로 관리합니다.

- **팔레트** 리넨 배경 `#f7f3ec`, 갈색 계열 텍스트 `#45372e`, 테라코타 포인트 `#a34f39` 하나. 일정 유형별 색은 쓰지 않습니다
- **글꼴** 제목 Gowun Batang, 본문 Gowun Dodum(Google Fonts), 대체 글꼴은 자체 호스팅 Pretendard. 시간·금액·전화번호는 고정폭 숫자
- **다크 모드** 기기 설정을 따름. 등장 모션은 `prefers-reduced-motion`을 지킴
- **형태** 과한 그림자·카드·장식 없이 1px 구분선과 절제된 모서리
- **터치** 터치 영역 44px 이상, 입력 글자 16px 이상(아이폰 확대 방지), safe-area 대응
- **반응형** 320px 화면부터 대응
- 스타일을 바꾸면 `index.html`의 `css/app.css?v=` 값을 올려 휴대폰 캐시를 갱신합니다

## 분석 규칙 요약 (`js/parser.js`)

- **제목** ① `행사명:` 같은 라벨 ② 원문 어디든 적힌 행사명(시상식·기공식·개소식·기념식·포럼 등과 그 앞의 이름, 예: `제5회 과천시민대상 시상식`) ③ 행사명이 없으면 **지역 + 하는 일**(`과천기공식`, `과천의전`). 모집 문구·인사·자기소개 줄은 제목으로 쓰지 않습니다
- **라벨** `일시`, `장소`, `담당`, `에이전시`, `페이`, `지급일`, `세금`, `특이사항` 등과 📍📞💰📅 이모지. 한 줄에 여러 라벨, 다음 줄에 오는 값도 처리
- **날짜·시간** `2026.10.24`, `10월 24일`, `10/24`, `오늘·내일·모레`, `다음주 금요일`, `오후 2시 반~6시`, `14:30`. 오전/오후 없는 1~6시는 오후로 추정하고 경고, 요일이 실제와 다르면 경고
- **페이** `25만원`, `25만 5천원`, `250,000원`, 단위 없는 `페이 30`(30만원으로 추정·경고)
- **세금공제** `3.3%`, `원천징수`, `공제 없음` 등. 언급이 없으면 빈칸
- **지급일** `당일 정산`, `익일`, `익월 10일`, `말일`, `2주 후`, 직접 적힌 날짜를 일정 날짜 기준으로 계산
- 일정 유형 분류는 화면에서 뺐습니다(`type` 필드는 데이터 호환용)

## 구조

```
index.html            앱 셸
css/app.css           디자인 토큰과 전체 스타일
js/app.js             해시 라우터, 하단 탭
js/parser.js          규칙 기반 분석기
js/store.js           localStorage 저장소(백업/복원 포함)
js/ics.js             .ics 생성, 아이폰 캘린더로 보내기
js/views/*.js         화면별 렌더링
tests/                분석기 테스트
assets/fonts/         Pretendard (OFL)
```

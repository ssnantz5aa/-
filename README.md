# Slate — 붙여넣는 일정 관리

받은 메시지·메일·공지 텍스트를 붙여넣으면 날짜, 시간, 장소, 연락처, 에이전시, 페이, 특이사항을 **규칙 기반으로** 추출해 캘린더에 등록하는 모바일 우선 웹앱입니다. AI나 외부 서버를 사용하지 않으며 모든 데이터는 기기(localStorage)에만 저장됩니다.

## 실행

빌드 과정이 없는 정적 웹앱입니다(ES 모듈 사용).

```bash
npm start          # http://localhost:5173
npm test           # 규칙 기반 분석기 테스트 (node --test)
```

어떤 정적 호스팅(GitHub Pages 등)에 올려도 동작합니다. 아이폰 Safari에서 공유 → ‘홈 화면에 추가’를 하면 앱처럼 실행됩니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 홈 | 날짜·인사말, 바로 쓰는 ‘일정 텍스트 붙여넣기’, 오늘 일정(시간순), 다가오는 일정 |
| 일정 추가 | 넓은 입력 영역, 붙여넣기·예시 넣기, 분석 중 진행 표시, 직접 입력 |
| 분석 결과 | 유형·제목·날짜·시간을 위에, 장소/연락처/에이전시/페이/특이사항을 그룹별로 표시. 값이 없는 항목은 ‘항목 추가’ 칩으로만 보이고, 불확실한 값은 은은한 경고로 표시. 원문 다시 보기, 하단 ‘캘린더에 등록’ |
| 캘린더 | 월간·주간·일간 보기, 오늘(링)과 선택한 날짜(채움) 구분, 유형별 색상, 스와이프 이동 |
| 일정 상세 | 전화·문자·지도·복사, .ics 내보내기(아이폰 캘린더), 복제, 수정, 삭제(실행 취소 가능) |
| 검색 | 제목·장소·담당자·에이전시·메모·원문 검색, 유형·기간 필터, 일치 부분 강조 |
| 설정 | 주 시작 요일, 12/24시간 표시, 기본 캘린더 보기, 백업 저장/불러오기, 전체 .ics 내보내기, 전체 삭제 |

## 디자인 시스템

`css/app.css` 상단의 토큰으로 관리합니다.

- **배경** 웜 화이트 `#FBFAF7`, 카드 `#FFFFFF`
- **텍스트** 블랙 `#121316`, 그레이 3단계 (`#45484E`, `#7C7F87`, `#B0B2B8`)
- **포인트 컬러** 코발트 블루 `#1E47C8` 하나만 사용
- **일정 유형** 채도를 낮춘 6색 — 촬영(인디고), 행사(테라코타), 미팅(세이지), 오디션(플럼), 레슨(오커), 기타(그레이)
- **글꼴** Pretendard Variable (자체 호스팅, 필요한 글자 범위만 내려받는 동적 서브셋, SIL OFL 1.1). 시간·금액·전화번호는 고정폭 숫자(tabular-nums)로 정렬
- **형태** 1px 헤어라인 구분선, 8–16px의 절제된 모서리, 그림자는 토스트·시트에만 사용. 그라데이션·유리 효과 없음
- **아이콘** 24px 그리드, 1.6 선 굵기의 통일된 선형 아이콘 (`js/icons.js`)
- **터치** 주요 터치 영역 44px 이상, 입력 글자 16px(아이폰 확대 방지), safe-area 대응
- **반응형** 320px 화면부터 대응, 640px 이상에서는 월간 칸에 일정 제목 표시, 1024px 이상에서는 왼쪽 레일 내비게이션

## 분석 규칙 요약 (`js/parser.js`)

- 라벨 인식: `일시`, `장소`, `담당`, `에이전시`, `페이`, `특이사항` 등 60여 개 라벨과 📍📞💰📅 이모지. 한 줄에 여러 라벨이 있으면 나눠서 처리하고, 값이 다음 줄에 오는 경우도 처리
- 날짜: `2026.10.24`, `10월 24일`, `10/24`, `오늘·내일·모레`, `다음주 금요일`, `24일`. 연도가 없으면 올해(두 달 넘게 지났으면 내년)로 보고, 적힌 요일과 실제 요일이 다르면 경고
- 시간: `오전 9시`, `오후 2시 반`, `14:30`, `9시~6시` 범위. 오전/오후가 없는 1–6시는 오후로 추정하고 경고
- 전화번호 정규화(`010-1234-5678`), 금액(`25만원`, `25만 5천원`, `250,000원`, 단위 없는 `페이 30` → 30만원으로 추정하고 경고)
- 유형 분류: 키워드 점수로 촬영/행사/미팅/오디션/레슨/기타를 구분

## 구조

```

css/app.css           디자인 토큰과 전체 스타일

js/parser.js          규칙 기반 분석기
js/store.js           localStorage 저장소(백업/복원 포함)
js/ics.js             iCalendar 내보내기
js/views/*.js         화면별 렌더링
tests/                분석기 테스트
assets/fonts/         Pretendard (OFL)
```
